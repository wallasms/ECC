# prompt-context-builder

## Quando usar

Use quando o pedido corresponder diretamente à descrição.

## Quando não usar

Não use para trabalho adjacente, ações destrutivas ou quando faltarem dados essenciais.

## Procedimento

1. Inspecione fontes e restrições relevantes.
2. Escolha a menor solução correta e rastreável.
3. Execute sem expor segredos ou enviar dados externamente.
4. Valide o resultado com o menor check executável.

## Saída esperada

Artefato pronto, fontes usadas, limitações e próximo passo.

## Checklist de validação

- [ ] Requisito atendido
- [ ] Dados sensíveis redigidos
- [ ] Sem dependência ou abstração desnecessária
- [ ] Verificação executada
